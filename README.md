# ATHLETIX Rowing V3 · 무료 기기 AI

선수 프로필·훈련·체크인·PB·대회·목표를 저장하고 기기에서 무료 AI를 실행하는 앱입니다. 사용자의 후속 요청에 따라 API 결제가 필요한 OpenAI 방식에서 키 없는 브라우저 추론으로 전환했습니다.

## 비용과 배포

필수 환경변수는 없습니다. 등록해 둔 OPENAI_API_KEY도 사용하지 않습니다. `/api/analyze`는 모든 POST를 403 `PAID_DISABLED`로 거절하고 외부 API를 호출하지 않습니다. 유료 서비스로 자동 전환하지 않습니다. 모델은 공개 저장소에서 내려받아 사용자 기기의 CPU와 메모리로 실행합니다. Vercel에 모델을 저장하거나 서버에서 추론하지 않습니다. 기존 호스팅 요금과 사용자의 통신 요금은 별도입니다.

정적 파일을 Vercel에 배포하면 됩니다. 빌드 명령이나 추가 프레임워크 설정은 없습니다.

## 앱에서 작동하는 기능

- **무료 AI 채팅:** Qwen2.5 0.5B Instruct를 Transformers.js 4.3.0 Web Worker/WASM으로 실행합니다. 고정 문구를 AI 답변으로 표시하지 않습니다. 실제 생성 결과와 스트리밍 텍스트를 보여 줍니다.
- **주간 분석:** 최근 7일·28일 기록, 이전 21일 주당 평균 대비 부하, 수면·컨디션·피로, PB 페이스를 정확히 계산해 즉시 표시합니다. 별도 버튼으로 기기 AI 해석을 생성합니다. 계산과 생성 답변은 구분합니다.
- **Concept2 사진:** Tesseract.js 6.0.1의 신경망 OCR 모델이 실제 이미지 글자를 기기에서 읽습니다. 거리·시간·500m 페이스·피치·와트를 추출하고 원문과 신뢰도를 표시합니다. 확인·수정한 값만 선수 기록으로 저장합니다.
- **사진 모델 추가 해석:** 선택적으로 SmolVLM 256M에 실제 이미지 텐서를 입력합니다. 영어 응답이고 숫자 정확도에 제한이 있으므로 OCR과 화면을 대조해야 합니다.
- **기록·프로필·PB·체크인·대회·목표·백업:** 기존 기능과 localStorage 데이터를 유지합니다.

채팅과 주간 AI에는 프로필, PB, 최근 7일/28일의 모든 훈련, 최근 28일의 컨디션·수면·피로, 대회, 목표, 날짜·시간대가 실제 모델 프롬프트에 포함됩니다. 대화는 최근 8개 메시지를 포함합니다. 6,144토큰을 넘으면 데이터를 임의로 생략하지 않고 오류 안내를 표시합니다. 선수 데이터와 사진은 AI 서버로 업로드하지 않습니다.

## 첫 사용과 기기 제한

채팅 모델은 처음 약 520MB, 선택적 사진 모델은 약 190MB를 다운로드합니다. 브라우저 캐시를 재사용하지만 Safari 데이터 삭제·캐시 축출 시 다시 다운로드할 수 있습니다. Wi-Fi를 권장합니다. 다운로드 진행률, 생성 중 텍스트, 중지 버튼을 제공합니다. 작은 기기 모델의 답변 품질과 속도는 상용 대형 모델보다 제한적입니다. 숫자는 앱의 계산 결과와 원본 기록을 기준으로 확인하세요. 메모리·다운로드·브라우저 오류는 화면에 표시합니다. 주간 계산과 OCR은 채팅 모델과 독립적입니다.

## 검증

`node --test tests/analyze.test.cjs tests/free-ai.test.cjs`

실제 로컬 HTTP POST에서 키 없음·기존 키 있음·잘못된 키 모두 403 PAID_DISABLED이고 외부 호출은 0회임을 검증했습니다. 모든 선수 데이터의 프롬프트 포함, 주간 계산, PB 페이스, 미인식 숫자를 추측하지 않는 OCR 파싱도 검사합니다.

2026-09-30 KST 공개 Qwen 모델의 실제 한국어 생성과 Tesseract 실제 이미지 인식을 실행했습니다. 합성 Concept2 테스트 화면의 2000m / 6:40.0 / 1:40.0 / 30spm / 350W를 정확히 인식했습니다. SmolVLM에 실제 이미지 텐서를 전달하고 응답을 얻었으나 이 테스트에서 숫자를 읽지 못했으므로 기본 인식은 OCR을 사용합니다. iPhone 실기기 성능은 이 환경에서 검증하지 않았습니다. 운영 브라우저 검증 결과는 배포 후 이 문서에 추가합니다.

이전 OpenAI 구현은 실제 요청에서 API 잔액 부족으로 거절되어 성공 응답을 확인하지 못했습니다. 현재 무료 버전은 OpenAI 연결 완료를 주장하지 않습니다.
